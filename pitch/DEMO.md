## Preflight

- The default case must be Comuna 4, revision 1, eight candidates, K=3, radius=1.8. Confirm greedy **81.0%** and exact **85.1%** before starting.
- Use a 1080p screen. Set browser zoom to 90% if needed; scroll deliberately between the map and comparison panel. Hide notifications, tabs with credentials and desktop clutter. Do not change the application's displayed values.
- Confirm the actual Qollab share URL and visitor-selected backend on the presentation machine. A local server is an explicit fallback, not evidence of platform integration.
- For the local preview: `uv run --no-project --with qiskit==2.5.2 --with numpy --with scipy python -m tools.preview_ui --port 8766`, then visit `http://127.0.0.1:8766`. It identifies itself as “Local test · BasicSimulator.”
- Rehearse one quantum attempt before presenting. On IonQ remote simulators the UI permits one attempt per Qollab Run and a low shot cap. Copy the case before Stop/Run; restarting the Qollab lifecycle clears edits. Never spend presentation time debugging a paid or queued backend.
- The supplied fallback was generated by `tools/record_pitch_demo.py`: one local simulator job, 64 requested shots, the real bridge and real UI. `media/evidence.json` records the result and displayed comparisons.
- Leave the exact result on screen long enough to read; rounded percentages are not percentage-point differences. The exact gap here is **4.073 percentage points**.

## Recovery lines

Backend slow: “The selected backend is still running. Here is our recorded local simulator check; the backend label and separate timings are visible.” Switch to the clip immediately; do not claim it is live or remote.

Backend unsupported: “This circuit/backend combination needs compatibility work. The classical comparison is available now; this local recording shows the quantum sampling path.” Do not switch simulator results into a hardware story.

QAOA misses the optimum: “That is this run's measured sample. Exact gives the small-case reference, and we rank by actual coverage.” A miss is a valid result; do not increase shots or launch hidden retries during the pitch.

Only 15 seconds remain: skip the detailed business number and say the pilot request. Never omit the caveats that interpret the displayed demo result.
